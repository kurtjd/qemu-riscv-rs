# qemu-riscv-pac
A peripheral access crate (PAC) for the [QEMU RISC-V virt](https://www.qemu.org/docs/master/system/riscv/virt.html)
platform.

**Note**: The SVD this PAC was generated from was LLM-generated so may contain inaccuracies.
Currently only contains fields for the UART, CLINT, and PLIC peripherals.
