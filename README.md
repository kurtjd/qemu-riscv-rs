# qemu-riscv-rs
This repo provides a PAC and Embassy HAL for the [QEMU RISC-V virt](https://www.qemu.org/docs/master/system/riscv/virt.html)
platform.

Currently only supports a basic blocking UART driver and embassy time-driver.

Note: The SVD the PAC was generated from was LLM-generated so may contain inaccuracies.
